# FitFoodie — AI Food Calorie Tracker

A Flutter mobile app that uses Google Gemini AI to identify food from photos and track your weekly calorie intake.

---

## What it does

- Take 3 photos of your meal — the app uses AI to identify the food and estimate calories
- Tracks your daily and weekly calorie budget
- Saves your meal history in real-time using Firebase
- Login with Email, Google, or Phone OTP

---

## Tech stack

- Flutter & Dart
- Firebase Auth, Firestore
- Google Gemini AI
- Riverpod (state management)
- MVVM architecture

## How to run

```bash
git clone https://github.com/priyath11/fitfoodie.git
cd fitfoodie
flutter pub get
flutter run
```

> Note: You will need your own Firebase config file and Gemini API key to run this project.
